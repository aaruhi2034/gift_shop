
## 📋 Project Overview

A comprehensive **Gift Shop Management System** designed to streamline retail operations, manage inventory, process billing, and generate insightful reports. This full-stack web application provides an intuitive interface for shop owners to efficiently manage their daily operations.

## ✨ Features

### 🔐 Authentication & Security
- JWT-based secure authentication
- Role-based access control
- Protected routes and API endpoints

### 📦 Product Management
- Add, edit, delete products
- Real-time stock tracking
- Category-wise product organization
- Low stock alerts

### 👥 Customer Management
- Customer registration and profile management
- Purchase history tracking
- Contact and address management

### 💰 Billing System
- Dynamic cart management
- Multiple payment modes (Cash, UPI, Card)
- Discount application
- Automatic invoice generation
- PDF download and print functionality

### 📊 Reports & Analytics
- Daily/Weekly/Monthly sales reports
- Inventory distribution charts
- Top selling products analysis
- Sales trend visualization

### 🎨 UI/UX Features
- Fully responsive design (Mobile, Tablet, Desktop)
- Dark/Light mode toggle
- Smooth animations with Framer Motion
- Interactive charts with Recharts
- Real-time notifications
